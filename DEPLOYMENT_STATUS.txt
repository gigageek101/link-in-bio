🚀 DEPLOYMENT INSTRUCTIONS:

OPTION 1: VERCEL DEPLOYMENT (Recommended - Easiest)
───────────────────────────────────────────────────
  1. Ensure you have Vercel CLI installed:
     npm install -g vercel

  2. Deploy:
     cd /Users/alexanderposch/Desktop/LinkInBio
     vercel deploy --prod

  3. Add environment variables in Vercel dashboard:
     - DOMAIN: your-domain.com
     - TELEGRAM_BOT_TOKEN: your-token
     - TELEGRAM_CHAT_ID: your-chat-id

  4. Verify: https://your-domain.com/allisonsundress

OPTION 2: NGINX DEPLOYMENT (Self-Hosted)
──────────────────────────────────────────
  1. Copy configuration:
     sudo cp nginx-meta-safe.conf /etc/nginx/sites-available/searchformylinks

  2. Create symlink:
     sudo ln -s /etc/nginx/sites-available/searchformylinks /etc/nginx/sites-enabled/

  3. Test configuration:
     sudo nginx -t

  4. Reload:
     sudo systemctl reload nginx

  5. Verify: curl -I https://your-domain.com/redirect?target=telegram
     Should show: HTTP/1.1 301 Moved Permanently

🛠️  TROUBLESHOOTING

Problem: "Redirects are 302, not 301"
Solution: Update Nginx config or Vercel settings. 301 must come from server,
          not JavaScript.

Problem: "Still seeing localStorage in console"
Solution: Make sure you're using script-safe.js, not old script.js
          Check: curl https://your-domain/allisonsundress.html | grep script-safe.js

Problem: "Age gate not showing"
Solution: Verify HTML has age-consent-modal div
          Check: curl https://your-domain/allisonsundress.html | grep age-consent-modal

Problem: "Links don't work after clicking I Agree"
Solution: Check /api/safe-redirect is deployed and working
          Test: curl https://your-domain/redirect?target=telegram
